# 🛡️ Cyber Phoenix - उन्नत सुरक्षा प्रणाली

## 🎯 मुख्य विशेषताएं

आपके लिए **5 शक्तिशाली सुरक्षा features** बनाए गए हैं:

### 1. 🔊 वॉयस असिस्टेंट अलर्ट सिस्टम
जैसे ही कोई खतरनाक लिंक मिलेगा, आपको **आवाज़ में चेतावनी** मिलेगी:

**Critical Threat पर:**
```
"गंभीर सुरक्षा खतरा पाया गया! यह Phishing हमला है जिसका
खतरा स्कोर 92 है। एक्सेस तुरंत ब्लॉक कर दिया गया है।
आगे न बढ़ें।"
```

**High Risk पर:**
```
"उच्च जोखिम खतरा पाया गया! यह Malware प्रतीत होता है
जिसका स्कोर 78 है। आपकी सुरक्षा के लिए यह वेबसाइट
ब्लॉक कर दी गई है।"
```

### 2. 🚫 स्वचालित वेबसाइट ब्लॉकिंग
- **High और Critical risk वाली websites automatically block** हो जाती हैं
- Blocked websites को दोबारा खोलने की कोशिश करोगे तो voice warning मिलेगी
- सभी blocked URLs एक list में save रहते हैं
- जरूरत पड़े तो manually unblock कर सकते हो

### 3. 📢 विस्तृत Desktop Notifications
जब भी threat detect होगा, आपको notification मिलेगी जिसमें होगा:
- ⚠️ Threat का नाम और level
- 📊 Risk Score (0-100)
- 📝 Top 3 खतरे के संकेत
- 🚫 Blocking status
- ⏰ समय की जानकारी

### 4. 📋 Blocked URLs की पूरी List
- सभी blocked websites एक जगह देख सकते हो
- हर website के बारे में पूरी जानकारी:
  - URL address
  - Threat score
  - Category (Phishing, Malware, etc.)
  - Block होने का कारण
  - कब block हुई
- चाहो तो unblock कर सकते हो

### 5. ⚙️ Advanced Settings
अपनी पसंद के अनुसार सेटिंग्स बदल सकते हो:
- 🔊 **Voice Alerts**: वॉयस चेतावनी on/off
- 🚫 **Auto-Block**: स्वचालित blocking on/off
- 🔔 **Browser Notifications**: डेस्कटॉप नोटिफिकेशन
- 🔊 **Sound Alerts**: आवाज़ की चेतावनी
- 📳 **Vibration**: मोबाइल पर कंपन
- 📏 **Alert Threshold**: कस्टम threshold (50-100)
- ⏱️ **Auto-hide Delay**: अलर्ट कब तक दिखे (3-30 seconds)

## 🚀 कैसे इस्तेमाल करें?

### स्टेप 1: सभी सुरक्षा features enable करो
1. पेज पर "Advanced Alert System" section में जाओ
2. Settings icon (⚙️) पर क्लिक करो
3. ये सब enable करो:
   - ✅ Enable Alerts
   - ✅ Sound Alerts
   - ✅ Voice Alerts (🔊)
   - ✅ Auto-Block Enabled (🚫)
   - ✅ Browser Notifications
   - ✅ Vibration Alerts

### स्टेप 2: Browser Permission दो
- जब browser notification की permission मांगे तो **"Allow"** करो
- यह सिर्फ एक बार होगा

### स्टेप 3: Suspicious Link Check करो
1. जो भी suspicious link/text है, वो input box में paste करो
2. "Analyze Content" button पर क्लिक करो
3. System अपने आप:
   - ✅ Analysis करेगा
   - ✅ Threat detect करेगा
   - ✅ आवाज़ में alert देगा
   - ✅ Desktop notification दिखाएगा
   - ✅ खतरनाक website को block कर देगा

### स्टेप 4: Blocked Websites देखो
- "Blocked Websites" section में जाओ
- "Show" button दबाओ
- सभी blocked URLs की list दिखेगी
- Unblock करना हो तो trash icon (🗑️) पर क्लिक करो

```

Action: तुरंत block
Vibration: 5 बार कंपन
Result: Website पूरी तरह block
```

### ⚠️ High (Score 65-84)
```
Voice: "उच्च जोखिम खतरा पाया गया!"
Action: स्वचालित block
Vibration: 3 बार कंपन
Result: Website block हो जाती है
```

### ⚡ Medium (Score 35-64)
```
Voice: "सावधान! मध्यम जोखिम पाया गया।"
Action: कोई block नहीं, पर चेतावनी
Vibration: 2 बार कंपन
Result: सावधानी से आगे बढ़ें
```

### ℹ️ Low (Score 0-34)
```
Voice: "कम जोखिम अलर्ट।"
Action: कोई block नहीं
Vibration: 1 बार कंपन
Result: Safe है, आगे बढ़ सकते हो
```
